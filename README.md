## 1. Οδηγίες Μεταγλώττισης
Για να κάνετε compile τον κώδικα, βεβαιωθείτε ότι έχετε εγκατεστημένη τη **Java 21** και το **Maven**.
Ανοίξτε ένα τερματικό στον φάκελο του project και τρέξτε την εντολή:
```bash
mvn clean package

## 2. Οδηγίες Εκτέλεσης
Αφού ολοκληρωθεί η μεταγλώττιση, υπάρχουν δύο τρόποι να τρέξετε την εφαρμογή:

**Α. Μέσω Maven:**
```bash
mvn exec:java

**Β. Μέσω του αρχείου JAR (μετά το compile):**
bash
java -jar target/prothypourgos-gia-mia-mera-1.0.jar

## 3. Οδηγίες Χρήσης
Η εφαρμογή είναι ένας διαδραστικός προσομοιωτής κρατικού προϋπολογισμού ("Πρωθυπουργός για μια μέρα") που λειτουργεί μέσω της κονσόλας.
Κατά την εκκίνηση, εμφανίζεται ένα μενού επιλογών, όπου ο χρήστης πληκτρολογεί τον αριθμό της ενέργειας που επιθυμεί (0-8) και πατάει `Enter`:

1. **Προβολή προϋπολογισμού:** Εμφανίζει τα συνολικά Έσοδα, Έξοδα και το τρέχον Ισοζύγιο, καθώς και μια συνοπτική λίστα των Υπουργείων.
2. **Εισαγωγή αλλαγής σε Υπουργείο:** Επιτρέπει την τροποποίηση των εξόδων ενός συγκεκριμένου Υπουργείου.
3. **Προβολή ιστορικού αλλαγών:** Εμφανίζει λίστα με όλες τις τροποποιήσεις που έχει κάνει ο χρήστης κατά τη διάρκεια της εκτέλεσης.
4. **Υπολογισμός ισοζυγίου:** Υπολογίζει το τελικό αποτέλεσμα (Πλεόνασμα/Έλλειμμα) και ελέγχει αν παραβιάζεται το όριο ελλείμματος (3%).
5. **Ανάλυση Εσόδων/Εξόδων ανά υπουργείο:** Δείχνει αναλυτικά τα έσοδα, τα έξοδα και το ισοζύγιο για κάθε υπουργείο ξεχωριστά.
6. **Εμφάνιση Top-3 Κατηγοριών:** Εμφανίζει τα 3 υπουργεία με τα υψηλότερα έσοδα ή έξοδα (μετά από επιλογή του χρήστη).
7. **Εκτέλεση Σεναρίων:** Επιτρέπει μαζικές αλλαγές βάσει σεναρίων (π.χ. αύξηση φόρων, περικοπές μισθών).
8. **Πολυεπίπεδη Ανάλυση:** Εμφανίζει αναλυτικά ποσοστά (%) συμμετοχής κάθε κατηγορίας εσόδων/εξόδων στον προϋπολογισμό και εκτιμώμενα μηνιαία ποσά.
0. **Έξοδος:** Τερματίζει την εφαρμογή.
